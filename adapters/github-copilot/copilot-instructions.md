# Critical Design Engineering — Copilot instructions

This repository follows the Critical Design Engineering conventions. Read `core/critical-design-engineering.md (the router — it matches the current moment to one skill in skills/)` for the full practice; the minimum is in `AGENTS.md` at the repo root.

When assisting here: record the why behind decisions (use templates/decision-record.md) before moving on; surface the dependencies and assumptions of generated code rather than presenting it as settled; propose seams — affordances for users to understand, configure, or contest — in user-facing work; raise design concerns before merge; and note that a named human must accept authorship of consequence for anything shipped.
